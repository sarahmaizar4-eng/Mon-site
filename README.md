# Sarah.M Portfolio

**Personal portfolio website for Sarah Maizar Said** — 19-year-old engineering student specialized in computer science. This site showcases her skills, projects, services, and includes an interactive AI chatbot assistant.

## Quick Start

Open `index.html` in your browser. Always open `index.html`, not `chatbot.html` (that's just the chat page alone). For best experience in VS Code, right-click `index.html` and select "Open with Live Server".

## Features

Single Page Application with smooth navigation without page reload. Hexagon-shaped bottom menu with active state highlighting. Animated skill bars that fill when you view the Skills section. Interactive hexagon cluster that rotates on mouse hover. Keyboard navigation using Arrow Left and Arrow Right keys. Fully responsive design that works on mobile, tablet, and desktop. Smart chatbot that answers questions about Sarah in natural language.

## Design System

Dark theme with gold accent. Background: #0b0b0f. Text: #f0ede6 (light cream). Accent color: #c9a96e (gold). Headings use Cormorant Garamond font (serif, elegant). Body text uses Syne font (sans-serif, modern). Cards have semi-transparent backgrounds with subtle borders.

## Technologies Used

HTML5 for structure. CSS3 for styling, animations, and responsive design. JavaScript for SPA navigation, chatbot logic, skill bar animations, and hexagon cluster rotation. Google Fonts for Cormorant Garamond and Syne fonts. SVG for icons and silhouette placeholders.

## Responsive Breakpoints

Desktop (>900px): Full layout with two columns. Tablet (600px to 900px): Simplified grid layout. Mobile (<600px): Stacked columns, hexagon cluster hidden for better touch experience. Navigation buttons resize and wrap on smaller screens.

## Installation

Download all files into a folder named "Project portfolio". No build steps or dependencies required. Works directly in any modern browser (Chrome, Firefox, Edge, Safari). No internet connection needed except for Google Fonts (fonts will fallback to system fonts if offline).

## For Teachers

The file `wireframe.html` contains the complete low-fidelity wireframe showing all 7 pages with placeholder boxes (gray rectangles) representing images, text, cards, and navigation. This demonstrates the layout structure before visual design. Open it separately to see the schematic version.
